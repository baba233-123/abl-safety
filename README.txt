ABL SAFETY POSTERS - phone app
==============================

What it is
- An app for your phone. No Claude, no login, no cost, and it works offline once installed.
- 30 topics and 33 posters, built from ABL's VPO Safety Pillar self-assessment (Aug 2026),
  the S.A.F.E. form, the Kinney method, the PPE standard AFR-VPOS.A09.001 and GTS.GEN.SFT.GSP.010.
- Every topic has a 5-slide toolbox talk and a training session of about 12 slides (PowerPoint),
  with speaker notes and a quiz.

STEP 1 - Put the app online (one time, free, about 5 minutes)
The app must be on a secure web address (https) before a phone can install it.

Easiest: Netlify Drop
 1. On a computer, open https://app.netlify.com/drop
 2. Sign up for a free account (email or Google).
 3. Unzip abl-safety-app.zip, then drag the "abl-safety-app" folder onto the page.
 4. Netlify gives you a web address, for example https://something.netlify.app
    You can rename it in Site settings, e.g. https://abl-safety.netlify.app

Alternative: GitHub Pages (free GitHub account). Upload the folder's contents to a repository
and turn on Pages in Settings > Pages.

STEP 2 - Install it on your phone
Android (Chrome): open the web address, tap the yellow "Install" bar, or menu (three dots) >
  "Install app" / "Add to Home screen".
iPhone (Safari): open the web address, tap Share > "Add to Home Screen".
The ABL Safety icon appears on your home screen and opens like any app.

Using it
- Today's poster appears when you open the app. A new one every day.
- Share poster: sends the image straight to WhatsApp (or any app).
- Copy text: WhatsApp-ready text with bold and ticks.
- Choose a topic: jump to any of the 30 topics.
- Edit wording: change any line; it saves on your phone.
- Learning materials: Toolbox talk or Training session for the topic on screen,
  shared as a PowerPoint file.

Sharing with supervisors
Send them the same web address. They install it the same way. Nobody needs an account.

Updating
If you change the files later, open sw.js and change "abl-safety-v1" to "abl-safety-v2",
then upload the folder again. Phones pick up the new version next time they open the app.
